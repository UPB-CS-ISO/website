# 03. Procese

## Veți învăța {/* #you-will-learn */}

- diferența dintre un **executabil** și un **proces**
- cum este **încărcat** un executabil într-un proces
- cum sunt create procesele cu `fork` și `exec`
- **stările** unui proces și ce sunt procesele **orfane** și **zombie**
- cum pornește Linux și de ce `init` nu se poate opri
- ce sunt **descriptorii de fișiere**
- ce sunt **legăturile simbolice**, cum sunt urmate și când sunt invalide
- cum să priviți în interiorul proceselor cu directorul `/proc`
- cum funcționează **redirectările** și **pipe-urile**, și fișierele speciale `/dev/null`, `/dev/zero` și `/dev/urandom`
