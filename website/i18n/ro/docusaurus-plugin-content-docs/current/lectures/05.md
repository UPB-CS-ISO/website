# 05. Utilizatori și permisiuni

## Veți învăța {/* #you-will-learn */}

- ce este un **utilizator** pentru kernel: o etichetă (**UID**-ul) sub care rulează fiecare proces și intervalele de UID-uri
- cum funcționează baza de date locală a utilizatorilor (`/etc/passwd`) și cum o citesc programele cu `getent`
- cum sunt stocate local parolele: **hash-uri**, **salt** și de ce se află în `/etc/shadow`
- ce sunt **grupurile** (`/etc/group`) și cum oferă drepturi mai multor utilizatori deodată
- ce se întâmplă când vă **autentificați** și cum primește un proces eticheta unui utilizator
- cine este utilizatorul **`root`** și cum deveniți `root` cu **`sudo`** și **`su`**
- cum funcționează **permisiunile fișierelor** (`r`, `w`, `x` pentru fișiere și directoare) și cum le modificați cu `chmod`, `umask`, `chown` și `chgrp`
- ce sunt **permisiunile speciale**: `setuid`, `setgid` și sticky bit
- de ce nu trebuie să vă bazați pe **prompt** ca să aflați cine sunteți
