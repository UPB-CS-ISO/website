# 05. Rețea

## Veți învăța {/* #you-will-learn */}

- o scurtă istorie a Internetului și ce sunt **serviciile de Internet** (Webul este unul dintre ele)
- ce sunt o **placă de rețea** și o **adresă MAC**
- cum arată un cadru **Ethernet** și unul **Wi-Fi**
- cum conectează **hub-urile** și **switch-urile** calculatoarele dintr-o rețea locală și de ce switch-urile au înlocuit hub-urile
- cum vă conectați la o rețea Wi-Fi cu `nmcli`
- ce sunt **adresele IP**, **măștile de rețea** și **ruterele**
- ce sunt **porturile**, **TCP** și **UDP**
- ce fac un **access point Wi-Fi** și un **gateway de acasă**
- de ce are nevoie un calculator pentru a ajunge în Internet: o **adresă IP și o mască**, un **default gateway** și un **server DNS**
- cum configurează **DHCP** toate acestea automat
