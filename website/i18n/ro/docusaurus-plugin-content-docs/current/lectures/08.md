# 08. Componente hardware

## Veți învăța {/* #you-will-learn */}

- cum rulează un **procesor** un program (fetch, decode, execute) și ce este o **arhitectură a setului de instrucțiuni** (ISA)
- cele trei arhitecturi pe care le veți întâlni: **x86-64**, **ARM** (`aarch64`) și **RISC-V**, diferența dintre **CISC** și **RISC** și de ce un program compilat pentru una nu rulează pe alta (`uname -m`, `file`, `Exec format error`)
- ce sunt **core-urile**, **thread-urile hardware** și procesoarele **hibride** și cum funcționează **ierarhia de memorie** (regiștri, cache, RAM, stocare)
- ce conține o **placă de bază** și ce este un **System on a Chip** (SoC), plus avantajele și dezavantajele unui PC față de un SoC (upgrade, consum, **unified memory**)
- ce sunt **northbridge** și **southbridge**, de ce northbridge-ul se află acum în capsula procesorului (Intel System Agent / SoC tile, AMD I/O die), ce face astăzi **chipset-ul** și de ce dispozitivele din spatele lui împart o singură legătură (`lspci`)
- cum funcționează **stocarea**: **HDD** și **SSD**, interfețele **SATA**, **NVMe** și **M.2**, TB vs GiB și cum denumește Linux discurile (`/dev/sda`, `/dev/nvme0n1`, `lsblk`)
- cum **comunică** componentele: harta legăturilor dintr-un PC, de ce legăturile sunt seriale, cum se calculează viteza unei legături (lane-uri, **biți vs octeți**), **PCIe**, **USB** (USB-C este o formă, nu o viteză), legături pentru ecrane și rețea și magistralele mici (I²C, SPI, UART) (`lsusb -t`)
- la ce folosesc **coprocesoarele**: **GPU** (integrat sau dedicat), **NPU**, motoarele media și de securitate și cum le arată Linux (`/dev/dri`, `/dev/accel`)
- cum se **inspectează** hardware-ul (`lshw`, `lscpu`, `lspci`, `lsusb`, `lsblk`, `free`) și cum se **măsoară** performanța (`top`, `dd`, `vmstat`)
