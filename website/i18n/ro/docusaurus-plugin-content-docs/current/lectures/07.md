# 07. Scripturi shell

## Veți învăța {/* #you-will-learn */}

- ce este o **expresie regulată** și cum o folosește `grep` pentru a găsi linii (`-E`, `-n`, `-c`, `-v`, `-o`, `-q`)
- ce este un **script shell**, cum îl faceți executabil (`chmod +x`) și ce face **shebang**-ul (`#!/bin/bash`)
- cum definiți **variabile**, cum capturați ieșirea unei comenzi cu `$(...)` și cum calculați cu `$((...))`, și de ce
  `$a+$b` este doar text
- ce este **codul de ieșire** al unei comenzi, de ce `0` înseamnă succes și cum înlănțuiți comenzi cu `&&` și `||`
- cum `if` și `while` **rulează o comandă** drept condiție și cum verifică `test` și `[ ... ]` (un program!) condițiile
- cum parcurge `for` **cuvinte** și cum numărați cu un **pas** (`{1..10..2}`, `seq`, `for ((...))`)
- cum scrieți **funcții** și cum dați un rezultat prin ieșire și prin codul de ieșire (`return`)
- cum citește un script **parametrii**: `$0`, `$1`, ..., `$#` și `"$@"`
