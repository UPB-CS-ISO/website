# 07. Dezvoltarea aplicațiilor

## Veți învăța {/* #you-will-learn */}

- diferența dintre limbajele **compilate**, **interpretate** și cele cu **bytecode** (hibride)
- ce oferă editoarele grafice de cod (VS Code / VSCodium, Zed) și **IDE-urile**
- ce sunt un **language server** (LSP) și un **debugger** și cum transformă ele un editor într-un IDE
- cum să depanați un program cu `gdb`
- etapele **compilării unui program C**: preprocesare, compilare, asamblare și link-editare (`gcc -E`, `-S`, `-c`)
- cum să scrieți un **`Makefile`** și unde se pun dependențele de fișierele header (`.h`)
- cum să compilați un proiect Rust cu **`cargo`**
