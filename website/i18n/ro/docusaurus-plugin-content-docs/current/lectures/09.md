# 09. Infrastructura rețelei

## Veți învăța {/* #you-will-learn */}

- o scurtă istorie a Internetului și ce sunt **serviciile de Internet** (Webul este unul dintre ele)
- ce sunt o **placă de rețea** și o **adresă MAC**
- cum arată un cadru **Ethernet** și unul **Wi-Fi**
- cum conectează **hub-urile** și **switch-urile** calculatoarele dintr-o rețea locală și de ce switch-urile au înlocuit hub-urile
- cum vedeți plăcile de rețea și rețelele Wi-Fi din jur cu `nmcli`
- ce sunt **adresele IP**, **măștile de rețea** și **pachetele IP** și cum testați un calculator cu `ping`
- cum ascunde **NAT** adresele private ale unei case în spatele unei singure adrese publice
- cum conectează **ruterele** rețelele și cum le vedeți cu `traceroute`
- ce sunt **porturile**, **TCP** și **UDP** și cum primește un program un port
- ce este **DNS**: cum devine un nume precum `upb.ro` o adresă IP și cum o cereți cu `host`
- de ce are nevoie un calculator pentru a ajunge în Internet: o **adresă IP și o mască**, un **default gateway** și un **server DNS**, și cum le configurează **DHCP** automat
- ce face un **ruter de acasă**: DHCP, DNS și **NAT**
- cum **capturați pachete** cu `tcpdump` și Wireshark
- ce verificați, de jos în sus, când nu aveți Internet
