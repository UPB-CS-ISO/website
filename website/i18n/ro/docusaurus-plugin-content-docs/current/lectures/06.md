# 06. Servicii de rețea

## Veți învăța {/* #you-will-learn */}

- ce sunt **porturile**, **TCP** și **UDP** și cum primește un program un port
- cum transformă **DNS** numele în adrese IP
- de ce are nevoie un calculator pentru a ajunge în Internet: o **adresă IP și o mască**, un **default gateway** și un **server DNS**, și cum le configurează **DHCP** automat
- cum configurați rețeaua **temporar** (`ip`, `dhclient`) și **permanent** (NetworkManager pe Fedora, netplan pe Ubuntu), cu o adresă **statică** sau **dinamică** (DHCP)
- ce verificați, de jos în sus, când nu aveți Internet
- ce face un **ruter de acasă**: DHCP, DNS și **NAT**
