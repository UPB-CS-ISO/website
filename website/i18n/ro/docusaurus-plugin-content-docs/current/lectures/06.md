# 06. Prelucrarea textului

## Veți învăța {/* #you-will-learn */}

- ce este un **filtru**: o comandă care citește fișiere sau `stdin`, schimbă textul și îl scrie la `stdout`
- cum vedeți și schimbați text cu `cat`, `sort`, `uniq`, `wc`, `head`, `tail`, `tac`, `rev`, `nl`, `cut` și `tr`
- ce este o **expresie regulată** și cum o folosește `grep` pentru a găsi linii (`-E`, `-n`, `-c`, `-v`, `-o`, `-q`)
- cum legați filtrele într-un **pipeline** cu `|` pentru a răspunde la o întrebare într-o singură linie
- ce este **codul de ieșire** al unei comenzi, de ce `0` înseamnă succes și cum înlănțuiți comenzi cu `&&` și `||`
