# Cursuri interactive

Cursurile în capitole scurte, parcurse în browser: terminale demo în care puteți scrie comenzi, simulatoare pas cu pas, întrebări și flashcards (în engleză). Progresul se salvează în browser.

<a className="button button--primary button--lg" href="/courses/index.html">Deschideți cursurile interactive →</a>

| Curs | Ce puteți încerca |
|---|---|
| <a href="/courses/02-files-management/index.html">02. Gestiunea fișierelor</a> | un explorator de căi, un vizualizator de pagini de manual, terminale demo cu misiuni |
| <a href="/courses/03-processes/index.html">03. Procese</a> | simulatoare pentru loader, stările proceselor, `fork` și `exec`, redirectări și pipe-uri |
| <a href="/courses/04-command-line/index.html">04. Interfața în linia de comandă</a> | simulatoare pentru terminale, sesiuni, variabile și linia de comandă, un terminal cu joburi |
| <a href="/courses/07-software-development/index.html">07. Dezvoltarea aplicațiilor</a> | simulatoare pentru compilare și `make`, terminale demo pentru `gcc`, `make` și `git` |

:::note

Cursurile interactive sunt material de studiu generat cu AI (Claude) din slide-uri, care urmează să fie verificat de profesori. Pentru examen, referința este cursul și slide-urile lui.

:::
