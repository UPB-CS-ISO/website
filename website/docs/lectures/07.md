## You will learn

- the difference between **compiled**, **interpreted** and **bytecode** (hybrid) languages
- what graphical code editors (VS Code / VSCodium, Zed) and **IDEs** offer
- what a **language server** (LSP) and a **debugger** are, and how they turn an editor into an IDE
- how to debug a program with `gdb`
- the steps of the **C compilation pipeline**: preprocessor, compiler, assembler and linker (`gcc -E`, `-S`, `-c`)
- how to write a **`Makefile`**, and where the header (`.h`) dependencies go
- what **git** is, what **commits** and **branches** are, the difference between `git commit` and `git push`, and the basic `git` commands
