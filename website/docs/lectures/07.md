# 07. Shell Scripting

## You will learn

- what a **regular expression** is and how `grep` uses it to find lines (`-E`, `-n`, `-c`, `-v`, `-o`, `-q`)
- what a **shell script** is, how to make it executable (`chmod +x`) and what the **shebang** (`#!/bin/bash`) does
- how to define **variables**, capture the output of a command with `$(...)` and compute with `$((...))`, and why
  `$a+$b` is just text
- what the **exit code** of a command is, why `0` means success, and how to chain commands with `&&` and `||`
- how `if` and `while` **run a command** as their condition, and how `test` and `[ ... ]` (a program!) check conditions
- how `for` goes over **words**, and how to count with a **step** (`{1..10..2}`, `seq`, `for ((...))`)
- how to write **functions** and give a result through the output and the exit code (`return`)
- how a script reads its **parameters**: `$0`, `$1`, ..., `$#` and `"$@"`
