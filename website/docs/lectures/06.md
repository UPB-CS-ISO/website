# 06. Text Processing

## You will learn

- what a **filter** is: a command that reads files or `stdin`, changes the text and writes it to `stdout`
- how to look at and change text with `cat`, `sort`, `uniq`, `wc`, `head`, `tail`, `tac`, `rev`, `nl`, `cut` and `tr`
- what a **regular expression** is and how `grep` uses it to find lines (`-E`, `-n`, `-c`, `-v`, `-o`, `-q`)
- how to chain filters into a **pipeline** with `|` to answer a question in one line
- what the **exit code** of a command is, why `0` means success, and how to chain commands with `&&` and `||`
