# 06. Network Services

## You will learn

- what **ports**, **TCP** and **UDP** are, and how a program gets a port
- how **DNS** turns names into IP addresses
- what a computer needs to reach the Internet: an **IP address and mask**, a **default gateway** and a **DNS server**, and how **DHCP** configures all of these automatically
- how to configure the network **temporarily** (`ip`, `dhclient`) and **permanently** (NetworkManager on Fedora, netplan on Ubuntu), with a **static** or a **dynamic** (DHCP) address
- what to check, from the bottom up, when there is no Internet
- what a **home router** does: DHCP, DNS and **NAT**
