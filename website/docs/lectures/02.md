## You will learn

- how files and folders are organized on Windows and Linux
- what **absolute** and **relative** paths are, and what `.` and `..` mean
- how to read the **manual pages** of a command
- how to navigate the file system with `pwd`, `cd`, `ls` and `tree`
- how to create, copy, move and delete files with `touch`, `mkdir`, `cp`, `mv` and `rm`
- how to use a terminal file manager (`yazi`)
