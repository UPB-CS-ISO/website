# Interactive Lectures

The lectures as short chapters you go through in the browser: demo terminals you can type in, step-by-step simulators, quizzes and flashcards. Your progress is saved in the browser.

<a className="button button--primary button--lg" href="/courses/index.html">Open the interactive lectures →</a>

| Lecture | What you can try |
|---|---|
| <a href="/courses/02-files-management/index.html">02. Files Management</a> | a path walker, a manual page viewer, demo terminals with missions |
| <a href="/courses/03-processes/index.html">03. Processes</a> | simulators of the loader, the process states, `fork` and `exec`, redirects and pipes |
| <a href="/courses/04-command-line/index.html">04. Command Line Interface</a> | simulators of terminals, sessions, variables and the command line, a terminal with jobs |
| <a href="/courses/07-software-development/index.html">07. Software Development</a> | simulators of compilation and `make`, demo terminals for `gcc`, `make` and `git` |

:::note

The interactive lectures are study material generated with AI (Claude) from the slides, to be reviewed by the lecturers. For the exam, the reference is the lecture and its slides.

:::
